COMPUTED SIGNALS: Pure functions , can use when creating value
can detect automatically if dependent variable change:
ex: i have number : 2
and i am creating another fn to compute the double of the number:
double = computed<number>(() => this.number() * 2) // whenever the number will be changed the double will also be changed because double is dependent on number
// improve performance optimization
NOTES: Do not call API in computed signals + Do not call "Set" and "update" method in it.
REACT: useMemo()
Angular : computed signals

##### EFFECTS: Used in Side effect of component(UI), console logging, Browser API handling, DOM access, Communicate with component, Auto logic run

::::  a "watcher" for signals : An effect() watches one or more signals. Whenever any of those signals change, Angular

automatically re-runs the effect function. You don't subscribe, you don't unsubscribe — Angular handles it.
The key rule: read a signal inside an effect → effect subscribes to it automatically.

Derive a value from signals:---->>>> computed()
Call an API when signal changes:---->>>> effect()
Format a display string :---->>>> computed()
Write to localStorage :---->>>> effect()
Calculate a total price :---->>>> computed()
Update a canvas/chart :---->>>> effect()
Log/analytics:---->>>> effect()

// Do not use set and update methods inside effect

📝 Quick Recap — Cheat Sheet

🔹 Signals Mindset
Signals replaced Zones — Angular now updates only changed parts, not the whole tree

🔹 signal()
Smart reactive variable
Read: count()
Update: .set() / .update()

🔹 computed()
Auto-calculated signal (like Excel formula)
Read-only
Do not use API calls inside

🔹 effect()
Runs side effects when signals change
Do not use .set() inside

🔹 {{ }}
Interpolation — display TS values in HTML
One-way binding (TS → HTML)

🔹 [ ]
Property binding — set HTML properties from TS
Used for: src, disabled, class

🔹 ( )
Event binding — HTML triggers TS methods
Use $event to capture event data

🔹 Two-way binding
Old: [(ngModel)]
Modern: [value] + (input) using signals

🔹 @if / @switch
Modern control flow
Replaces *ngIf / *ngSwitch

🔹 @for
Modern loop
Always use track
Helpers: $index, $first, $last, $even, $odd

🔹 Pipes
Format data in templates
Built-in: uppercase, date, currency, json
Custom: ng g p

🔹 Parent → Child
Pass data: [data]="value"
Receive in child: input<type>()

🔹 Components
Self-contained (HTML + CSS + TS)
Use @Component
Standalone by default

🔹 CLI Commands
ng g c → component
ng g s → service
ng g p → pipe
ng serve → run project
